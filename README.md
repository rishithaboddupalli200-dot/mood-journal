# 🌸 Mood Journal

A simple and interactive mood-tracking application built with React. Record your daily feelings, reflect on your experiences, and visualize your mood history.

## ✨ Features

- Select your mood using emojis.
- Write and save daily journal entries.
- View previous entries with dates.
- Delete journal entries.
- Visualize mood history with an interactive chart.
- Automatically save entries using browser localStorage.

## 🛠️ Technologies Used

- React
- JavaScript
- CSS
- Recharts
- Vite
- localStorage

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/rishithaboddupalli200-dot/mood-journal.git
```

Navigate to the project directory:

```bash
cd mood-journal
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
